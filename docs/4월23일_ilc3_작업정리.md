### Step 2 — TX 보드 RTL 작성

#### 생성 파일
- `rtl/top_ilc3_tx_board.v`
- `constraints/ilc3_tx_board.xdc`
- `tcl/create_project_ilc3_tx.tcl`

#### 보드 역할
- **Board 1**: COM3 = UART 로그, COM8 = JTAG
- PMOD JD (Bank 34): `ilc3_amp[3:0]`, `ilc3_amp_valid`, `ilc3_frame_start`, `ilc3_frame_end` → RX 보드 출력
- PMOD JC (Bank 34): `rx_ready_in`, `pkt_done_in` ← RX 보드 입력, `tx_sym_dbg[1:0]` → AD3 디버그
- UART JE1 (V12): TX 전용 (115200 baud)

#### 프레임 포맷 (12 bytes)
```
[AA][55][08][SEQ3][SEQ2][SEQ1][SEQ0][DE][AD][BE][EF][CRC8]
```
- CRC-8 (poly=0x07, init=0x00): bytes 2~10 (9바이트) 커버
- 48 symbols × 2 samples = 96 amplitude samples/frame

#### 주요 RTL 블록
| 블록 | 설명 |
|------|------|
| Reset synchronizer | 3-FF, active-low rst_btn_n |
| CRC-8 함수 | 조합 체인으로 frame_crc 사전 계산 |
| Frame byte mux | case(byte_cnt 0..11) → cur_byte |
| Symbol mux | case(sym_cnt 0..3) MSB-first, 2bit씩 |
| TX FSM | F_IDLE → F_SYM → F_DELAY(8클럭) → F_IDLE |
| ilc3_tx_core | sym당 3클럭, amp_out_ready=1 고정 |
| amp_cnt[6:0] | 0..95 추적; 0=frame_start, 95=frame_end |
| UART logger | 1초마다 "TX PKT=XXXXXXXX\r\n" (17바이트) |

#### UART 출력 예시
```
TX PKT=00000001
TX PKT=00000002
...
```

### Step 3 — RX 보드 RTL 작성

#### 생성 파일
- `rtl/top_ilc3_rx_board.v`
- `constraints/ilc3_rx_board.xdc`
- `tcl/create_project_ilc3_rx.tcl`

#### 보드 역할
- **Board 2**: COM7 = UART 로그, COM9 = JTAG
- PMOD JD (Bank 34): `ilc3_amp[3:0]`, `ilc3_amp_valid`, `ilc3_frame_start`, `ilc3_frame_end` ← TX 보드 수신
- PMOD JC (Bank 34): `rx_ready_out`, `pkt_done_out` → TX 보드, `crc_pass_dbg`, `crc_fail_dbg` → AD3
- UART JE1 (V12): RX 전용 (115200 baud)

#### 주요 RTL 블록
| 블록 | 설명 |
|------|------|
| Reset synchronizer | 3-FF, active-low rst_btn_n |
| 2-FF 입력 동기화 | `(* ASYNC_REG="TRUE" *)` amp_s1/s2, av_s1/s2, fs_s1/s2, fe_s1/s2 |
| need_resync | fs_s2 감지 시 set, 첫 sym_out_valid 시 clear → 프레임 경계 정렬 |
| ilc3_rx_core | sym_out_ready=1 고정, 3클럭 파이프라인 딜레이 |
| sym_to_byte | sym_in_byte 0..3 누적 → rx_buf[0..11] 저장 |
| CRC 검증 FSM | CK_IDLE → CK_CALC(rx_buf[2..10], 1바이트/클럭) → CK_RESULT |
| ok_cnt/ng_cnt | 32비트 카운터, CRC pass/fail 누적 |
| UART logger | 1초마다 "RX OK=XXXXXXXX NG=XXXXXXXX\r\n" (28바이트) |

#### UART 출력 예시
```
RX OK=00000012 NG=00000000
RX OK=00000025 NG=00000001
...
```

#### CDC 처리 (중요)
- TX/RX 보드는 **독립적인 125MHz 크리스탈** 사용 → PMOD 신호가 비동기
- 2-FF synchronizer + `set_false_path` XDC 제약으로 처리
```xdc
set_false_path -from [get_ports {ilc3_amp[*]}]
set_false_path -from [get_ports ilc3_amp_valid]
set_false_path -from [get_ports ilc3_frame_start]
set_false_path -from [get_ports ilc3_frame_end]
```

#### CRC 타이밍 설계 결정
- 조합 9-byte CRC 체인(~216 LUT 레벨)은 125MHz 위반 → **순차 FSM** 방식 채택
- 1바이트/클럭 × 9클럭 = CRC 완료 (프레임 수집 시간 144+ 클럭 대비 안전)

| ilc3_frame_end | V17 | out | in |
